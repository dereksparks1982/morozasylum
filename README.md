# morozasylum
Run an asylum

## Development candidate 0.1
A playable browser foundation for Moroz Asylum, the fictional institution in the small industrial Soviet town of Cherny Bor. It has a desk, management indicators, wards, staff, town directory, journal, simple charts and decisions. The era is not fixed. Open index.html or the GitHub Pages deployment to test.

See DESIGN.md for setting, historical inspiration, open decisions and source links.

Unvalidated candidate. Figures and events are illustrative, not historical claims.
